# Profit Leak Intelligence
### Retail Profitability & Loss Opportunity Analysis | Power BI

## Project Overview

Profit Leak Intelligence is an interactive Power BI project designed to analyse retail sales performance, identify potential profitability risks, and explore how discount adjustments may influence profit.

The project transforms retail transaction data into meaningful business insights through interactive dashboards, DAX measures, and a What-if discount simulation.

## Business Objectives

- Monitor overall sales and profitability performance.
- Analyse sales trends across different periods.
- Compare sales performance across product categories.
- Evaluate profit contribution across regions.
- Identify products with low or negative profitability.
- Explore the potential impact of discount adjustments on profit.

## Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- CSV Dataset

## Dataset

**Dataset:** Sample Superstore Sales Dataset

The dataset contains retail transaction details, including:

- Order and shipping information
- Customer and geographical details
- Product categories and sub-categories
- Sales, quantity, discount, and profit

## Data Preparation

Data preparation was performed using Power Query.

Key activities included:

- Reviewing column quality and data types.
- Correcting date formats.
- Assigning appropriate data types to numerical and categorical columns.
- Checking for data errors.
- Removing duplicate records.

## Dashboard Features

### Page 1: Executive Overview

Provides a high-level view of retail business performance.

**Key Performance Indicators:**
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Order Value

**Visualisations:**
- Monthly Sales Trend
- Sales by Category
- Profit by Region

### Page 2: Profit Leak Analysis

Focuses on identifying potential profitability risks.

**Visualisations:**
- Discount vs Profit Analysis
- Bottom 10 Least Profitable Products
- Discount What-if Simulation

**What-if Analysis:**

An interactive discount adjustment parameter allows users to explore estimated profit changes under different target discount assumptions.

The simulation is an analytical estimate based on the selected target discount, not a guaranteed prediction of future profit.

## DAX Measures

The project includes measures for:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Discount
- Total Quantity
- Average Order Value
- Loss-Making Orders
- Simulated Profit

## Key Business Insights

- Higher discounts can put pressure on profitability.
- Products with low or negative profit require further investigation.
- Sales performance and profit contribution should be evaluated together.
- Discount adjustments can be explored to understand potential profitability improvements.

## Project Outcome

This project demonstrates the use of Power BI for data preparation, DAX calculations, interactive dashboard development, profitability analysis, and business-focused reporting.
